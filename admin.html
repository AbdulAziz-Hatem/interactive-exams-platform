    إضافة المقررات، إنشاء الاختبارات، وتغذية بنوك الأسئلة يدوياً أو دفعة واحدة.

    صلاحيات المدير الأكاديمي

    1. إضافة مقرر / مادة دراسية جديدة

    2. إنشاء اختبار جديد لمقرر

    3. إضافة سؤال فردي إلى اختبار

    خيارات الإجابة (حدد الإجابة الصحيحة عبر زر الراديو)

    4. الاستيراد السريع لبنك الأسئلة دفعة واحدة (Bulk JSON)

    يمكنك استيراد عشرات أو مئات الأسئلة في ثانية واحدة بلصق مصفوفة JSON معدة مسبقاً.
