    إدارة بنوك الأسئلة والمقررات التخصصية

    إضافة المقررات، إنشاء النماذج الاختبارية، وتغذية بنوك الأسئلة يدوياً أو دفعة واحدة لطلبة القسم.

    صلاحيات الإشراف الأكاديمي

    1. إضافة مقرر دراسي تخصصي جديد بالقسم

    2. إنشاء نموذج اختباري جديد لمقرر

    3. إضافة مسألة فردية مع خياراتها وتعليلها العلمي

    خيارات الإجابة (حدد الإجابة الصحيحة عبر زر الراديو)

    4. الاستيراد السريع لبنك الأسئلة دفعة واحدة (Bulk JSON)

    يمكنك استيراد عشرات أو مئات الأسئلة التخصصية في ثوانٍ بلصق مصفوفة JSON معدة مسبقاً.
