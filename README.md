# منصة مدارج للاختبارات التفاعلية والتقييم الذاتي 🎓
**Madarej Interactive Exam & Assessment Platform**

منصة إلكترونية تعليمية حديثة، مصممة بأعلى معايير الوصول الرقمي (WCAG 2.1 AA) والتوافقية التامة مع قارئات الشاشة (Screen Readers)، لتمكين الطلاب من خوض الاختبارات التفاعلية، ومراجعة المواد الدراسية، وتقييم الفهم والاستيعاب مع التغذية الراجعة الفورية.

---

## ✨ المميزات الرئيسية للمنصة

1. **نظام مصادقة متكامل (Authentication)**:
   - تسجيل حساب جديد بالاسم، البريد الإلكتروني، وكلمة المرور.
   - تسجيل الدخول الآمن، وإدارة الجلسات، واستعادة كلمة المرور.
   - الفصل بين صلاحيات الطلاب وصلاحيات الإدارة.

2. **بيئة اختبار تفاعلية آمنة (Anti-Cheating & Server-Side Evaluation)**:
   - جلب أسئلة الاختبار دون كشف الإجابات الصحيحة في المتصفح أو في حركة الشبكة (Network Inspect).
   - مؤقت تنازلي ذكي مع إشعارات صوتية واضحة لقارئ الشاشة عند اقتراب انتهاء الوقت.
   - خيارات إجابة مجمعة داخل وسوم وصول قياسية (`<fieldset>` و `<legend>` و `role="radiogroup"`).
   - شريط تقدم تفاعلي معلن لحظياً عبر `aria-valuenow`.

3. **تقييم سحابي فوري وتغذية راجعة مفصلة (Detailed Review & Explanations)**:
   - تصحيح آمن داخل محرك قاعدة البيانات عبر دالة `submit_exam_answers`.
   - حساب الدرجة والنسبة المئوية وحالة الاجتياز (ناجح / راسب).
   - استعراض مفصل لكل سؤال مع توضيح إجابة الطالب، والإجابة النموذجية الصحيحة، والتعليل العلمي والشرح.

4. **لوحة الطالب الشخصية (Student Dashboard)**:
   - سجل تاريخي لجميع الاختبارات السابقة والدرجات المحققة ونسب النجاح.
   - إمكانية إعادة مراجعة أي اختبار سابق بضغطة زر.

5. **لوحة تحكم إدارية مرنة (Admin Control Panel)**:
   - إضافة وإدارة المقررات والمواد الدراسية.
   - إنشاء الاختبارات وتحديد أزمنتها ونسب النجاح المطلوبة.
   - إضافة الأسئلة يدوياً أو **الاستيراد السريع لبنوك الأسئلة (Bulk JSON Import)** لإضافة مئات الأسئلة دفعة واحدة.

6. **وضع الجاهزية المزدوج (Hybrid Architecture)**:
   - **وضع التجربة والمحاكاة الفورية (Local Demo Mode)**: يعمل مباشرة في أي متصفح دون الحاجة لأي إعداد أو سيرفر خارجي.
   - **الوضع السحابي المباشر (Supabase + Netlify Live)**: ربط سلس مع قاعدة بيانات سحابية PostgreSQL بضغطة زر.

## 🏗️ هيكلية المشروع (Project Architecture)

```
interactive-quiz-platform/
├── index.html              # الصفحة الرئيسية واستعراض المواد والمقررات
├── auth.html               # شاشة تسجيل الدخول وإنشاء حساب جديد
├── dashboard.html          # لوحة الطالب الشخصية وسجل الاختبارات
├── subject.html            # استعراض الاختبارات الخاصة بمادة معينة
├── exam.html               # محرك جلسة الاختبار التفاعلي والمؤقت
├── result.html             # تقرير النتيجة، المراجعة التفصيلية والتعليلات
├── admin.html              # لوحة إدارة المواد وإنشاء الاختبارات وبنوك الأسئلة
├── netlify.toml            # إعدادات النشر والحماية وإعادة التوجيه لـ Netlify
├── supabase_schema.sql     # مخطط قاعدة البيانات الكامل + سياسات RLS + دوال التقييم
├── css/
│   └── style.css           # التصميم المتاح والمتجاوب، الوضعين الليلي والنهاري
└── js/
    ├── config.js           # إعدادات الربط السحابي ومفاتيح المشروع
    ├── a11y.js             # محرك إمكانية الوصول والتنبيهات الصوتية لقارئات الشاشة
    ├── auth.js             # إدارة الجلسات والمصادقة والتحقق من الصلاحيات
    ├── db.js               # طبقة الاتصال والتعامل مع البيانات والتقييم السحابي
    └── exam.js             # إدارة جلسة الاختبار والتنقل بين الأسئلة وحفظ الإجابات
```

## 🚀 طريقة التشغيل والنشر

### 1. النشر على Netlify عبر GitHub:
1. رفع مجلد المشروع إلى مستودع جديد على حسابك في GitHub (مثل: `AbdulAziz-Hatem/interactive-exams-platform`).
2. الدخول إلى لوحة Netlify واختيار `Add new site` ثم `Import an existing project` من GitHub.
3. يقوم Netlify تلقائياً بالبناء والنشر في ثوانٍ معدودة.

### 2. تفعيل قاعدة البيانات السحابية (Supabase):
1. إنشاء مشروع مجاني جديد على [Supabase.com](https://supabase.com).
2. فتح قسم **SQL Editor**، ولصق محتوى ملف `supabase_schema.sql` ثم الضغط على **Run**.
3. نسخ `Project URL` و `anon public key` من إعدادات المشروع (Project Settings -> API).
4. لصق المفاتيح عبر زر **\"⚙️ ربط السحابة\"** في الصفحة الرئيسية للموقع، وسيتم التفعيل فورياً!
